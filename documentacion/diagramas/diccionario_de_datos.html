Diccionario de Datos del Sistema VERTEX

Especificación Exhaustiva del Subsistema de Persistencia y Aislamiento Multi-Slot (user://)

El presente Diccionario de Datos describe de manera formal la arquitectura de persistencia jerárquica y desacoplada del sistema VERTEX. La estructura está compuesta por ocho entidades maestras gobernadas por el administrador de ranuras SlotManager mediante archivos ConfigFile en user://, garantizando aislamiento total entre perfiles de usuario, integridad de registros históricos, resiliencia transaccional y rotación de copias de seguridad.

1. Entidad: SlotMeta (Metadatos Globales de Ranuras)

Archivo Físico: user://slots.cfg | Sección: [slots] | Ámbito: Global del Sistema
Campo / Clave Tipo Físico Rango / Dominio Restricción Clave Default Descripción y Reglas de Integridad
config_id String 32 caracteres NOT NULL PK "meta_global" Identificador único del archivo maestro de metadatos.
active_slot int 1 .. 3 NOT NULL Atributo 1 Puntero al índice de la ranura actualmente activa. Restringido a [1, 3].
migrated_legacy bool Boolean (0/1) NOT NULL Atributo false Flag que certifica la migración atómica de saves planos anteriores a la versión multi-slot.

2. Entidad: SaveSlot (Contenedor de Ranura de Guardado)

Ubicación Física: user://slots/slot_X/ | Ámbito: Ranura Aislada (1..3)
Campo / Clave Tipo Físico Rango / Dominio Restricción Clave Default Descripción y Reglas de Integridad
slot_id int 1 .. 3 NOT NULL PK N/A Número ordinal que identifica inequívocamente la ranura.
is_empty bool Boolean (0/1) NOT NULL Atributo true Indica si la ranura está vacía o contiene un perfil activo en uso.
updated_at int Unix Epoch (seg) NOT NULL Atributo 0 Marca de tiempo de la última operación de escritura atómica sobre la ranura.
cached_stars int 0 .. 45 NOT NULL Atributo 0 Caché rápida del total acumulado de estrellas obtenidas, para lectura ágil sin I/O pesado.
slot_path String 128 caracteres NOT NULL Atributo "user://slots/slot_X" Ruta física normalizada del directorio de la ranura.

3. Entidad: Profile (Identidad del Operador / Analista)

Archivo Físico: user://slots/slot_X/profile.cfg | Sección: [profile]
Campo / Clave Tipo Físico Rango / Dominio Restricción Clave Default Descripción y Reglas de Integridad
profile_id String 36 caracteres NOT NULL PK UUID v4 Identificador único del expediente del operador.
slot_id int 1 .. 3 NOT NULL FK N/A Clave foránea hacia SaveSlot.slot_id.
player_name String 1 a 32 caracteres NOT NULL Atributo "Operador" Alias táctico del usuario. Se valida contra inyecciones y caracteres no imprimibles.
avatar_icon String 32 caracteres NOT NULL Atributo "agent_blue" Clave de textura para renderizado del avatar en el HUD y menús.
theme_color String 7 caracteres (#HEX) NOT NULL Atributo "#00E5FF" Color hexadecimal utilizado para personalizar el HUD y trazos del grafo.

4. Entidad: LevelProgress (Progresión de Niveles y Calificación)

Archivo Físico: user://slots/slot_X/progress.cfg | Sección: [estrellas]
Campo / Clave Tipo Físico Rango / Dominio Restricción Clave Default Descripción y Reglas de Integridad
level_key String 32 caracteres NOT NULL PK Comp. N/A Identificador canónico del nivel táctico (ej. "sector_0_1").
slot_id int 1 .. 3 NOT NULL FK Comp. N/A Clave foránea hacia SaveSlot.slot_id.
stars int 0 .. 3 NOT NULL Atributo 0 Estrellas de maestría obtenidas según la optimización del coste de aristas.
mejor_coste float Flotante $\ge 0.0$ NOT NULL Atributo 0.0 Mejor coste computado por el algoritmo Dijkstra para resolver el escenario.
completed bool Boolean (0/1) NOT NULL Atributo false Indica si el escenario ha sido superado (stars > 0), desbloqueando los subsiguientes.

5. Entidad: GlobalStats (Métricas Globales de Rendimiento)

Archivo Físico: user://slots/slot_X/stats.cfg | Sección: [stats]
Campo / Clave Tipo Físico Rango / Dominio Restricción Clave Default Descripción y Reglas de Integridad
stats_id String 32 caracteres NOT NULL PK "stats_main" Identificador único del registro de estadísticas de la ranura.
slot_id int 1 .. 3 NOT NULL FK N/A Clave foránea hacia SaveSlot.slot_id.
total_wins int $\ge 0$ NOT NULL Atributo 0 Total acumulado de victorias conseguidas en cualquiera de los modos de juego.
total_losses int $\ge 0$ NOT NULL Atributo 0 Total acumulado de derrotas (infección total de núcleo o captura hostil).
best_streak int $\ge 0$ NOT NULL Atributo 0 Racha máxima de victorias consecutivas sin interrupción de derrotas.
total_attempts int $\ge 0$ NOT NULL Atributo 0 Cantidad total de intentos de partida iniciados por el operador.
play_time int Segundos $\ge 0$ NOT NULL Atributo 0 Tiempo neto de simulación activa en segundos transcurridos.

6. Entidad: LevelStats (Métricas Discretas por Nivel)

Archivo Físico: user://slots/slot_X/stats.cfg | Sección: [levels]
Campo / Clave Tipo Físico Rango / Dominio Restricción Clave Default Descripción y Reglas de Integridad
level_key String 32 caracteres NOT NULL PK Comp. N/A Identificador canónico del nivel evaluado.
slot_id int 1 .. 3 NOT NULL FK Comp. N/A Clave foránea hacia SaveSlot.slot_id.
wins int $\ge 0$ NOT NULL Atributo 0 Conteo de victorias en este escenario específico.
losses int $\ge 0$ NOT NULL Atributo 0 Conteo de derrotas en este escenario específico.

7. Entidad: BadgeRecord (Registro de Méritos e Insignias)

Subsistema: BadgeRegistry | Ámbito: Sincronizada en Perfil
Campo / Clave Tipo Físico Rango / Dominio Restricción Clave Default Descripción y Reglas de Integridad
badge_id String 32 caracteres NOT NULL PK Comp. N/A Clave única de la condecoración (ej. "first_clear", "speed_demon").
slot_id int 1 .. 3 NOT NULL FK Comp. N/A Clave foránea hacia SaveSlot.slot_id.
unlocked bool Boolean (0/1) NOT NULL Atributo false Estado del mérito (verdadero si se ha alcanzado la meta).
current_metric int $\ge 0$ NOT NULL Atributo 0 Valor de avance registrado hacia la condición de adjudicación.
target_metric int $> 0$ NOT NULL Atributo 1 Meta cuantitativa que dispara el desbloqueo del mérito.

8. Entidad: SlotSnapshot (Snapshots Atómicos Rotativos)

Ubicación Física: user://slots/slot_X/backups/ | Ámbito: Ranura Aislada
Campo / Clave Tipo Físico Rango / Dominio Restricción Clave Default Descripción y Reglas de Integridad
snapshot_name String 64 caracteres NOT NULL PK N/A Identificador de carpeta con patrón snapshot_<timestamp>_<tag>.
slot_id int 1 .. 3 NOT NULL FK N/A Clave foránea hacia SaveSlot.slot_id.
tag String 16 caracteres NOT NULL Atributo "auto" Etiqueta funcional del respaldo ("auto", "pre_delete", "manual").
timestamp int Unix Epoch (seg) NOT NULL Atributo N/A Marca de tiempo exacta de generación del snapshot.
files_archived Array[String] 3 elementos NOT NULL Atributo [3 files] Copia atómica de los tres archivos maestros (progress.cfg, profile.cfg, stats.cfg).
