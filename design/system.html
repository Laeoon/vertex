3. Anti-Overlap & Single-Source HUD Rules

✓ Zero Duplication

Every metric and action exists in exactly ONE place. No duplicate right-side Hacker exploit box, no duplicate "Ve hacia..." pill in the bottom dock, and no duplicate keyboard legend when action buttons already show their shortcut keycap.

✓ Dynamic Width Flow (No Collisions)

Every pill and button computes its width from its text length + 28px padding with a strict 10px gap. Buttons never collide like "[1] SEGMENTAR ARISTA[2] FIREWALL".
